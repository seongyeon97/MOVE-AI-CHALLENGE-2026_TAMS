# PRD 6장 「안전운전 스코어링 모델」 정리

## 0. 이 문서에 대하여

이 문서는 `화물차 안전운전 스코어링 플랫폼 PRD_0728.html`의 6장 「안전운전 스코어링 모델」을 확인해 정리한 것입니다. 표에 적힌 산식뿐 아니라 6.4 시뮬레이터의 실제 자바스크립트 계산 로직까지 대조해, 문서에 글로 적히지 않은 세부 동작(보정계수 계산, Scope 3 감축 추정식 등)도 함께 반영했습니다.

주의할 점은 이 PRD의 점수 모델이 현재 기사 뷰 프로토타입의 점수식과 서로 다른 모델이라는 것입니다. 그 차이는 6절에 따로 정리했습니다.

## 1. 기본 골격

- 100점에서 시작해 항목별로 감점합니다.
- 산식과 임계값을 사용자에게 전부 공개하는 것을 전제로 설계합니다.
- 문서 전체가 이 모델을 "운전자 평가 도구가 아니라 안전운전 사실을 증빙하는 도구"로 규정합니다.
- 점수는 규칙 기반·결정론적 엔진이 산출하고, LLM은 그 점수를 읽어 설명문만 생성합니다. LLM은 점수 필드에 쓰기 권한이 없어, 점수는 항상 재현 가능하고 LLM이 흔들 수 없습니다.

## 2. 6개 평가 항목 (6.1)

100점을 여섯 항목에 배분하고, 각 항목은 100km당 이벤트 건수(n₁₀₀)를 기준으로 감점합니다.

| ID | 항목 | 배점 | 감점 산식 (100km 환산) | 보정 |
|---|---|---|---|---|
| ITM-01 | 가속 안정성 (급가속·급출발) | 12 | min(12, max(0, n₁₀₀ − 2.0) × 1.2) | 적용 |
| ITM-02 | 감속 안정성 (급감속) | 13 | min(13, max(0, n₁₀₀ − 2.0) × 1.3) | 적용 |
| ITM-03 | 속도 준수 (과속) | 25 | min(25, 과속지속분 × 1.6) | 미적용 |
| ITM-04 | 차로 변경·회전 | 10 | min(10, max(0, n₁₀₀ − 1.0) × 1.5) | 적용 |
| ITM-05 | 피로 관리 (연속운행·야간) | 25 | min(25, max(0, 최대연속h − 4)×7 + max(0, 야간비율 − 0.25)×12) | 미적용 |
| ITM-06 | 환경 리스크 대응 | 15 | min(15, 감속 미준수율 × 15) | 미적용 |
| 계 | | 100 | | |

임계값(예: 2.0회/100km)은 PoC용 잠정값이며, 실제 운행 데이터 분포의 중위값으로 다시 조정하는 것을 전제로 한다고 캡션에 적혀 있습니다. 아직 확정된 숫자가 아닙니다.

## 3. 총점·등급 (6.2)

총점 산식은 다음과 같습니다.

```
안전운전도 = 100 − Σ ( 항목별 감점ᵢ ÷ 보정계수ᵢ )
// 보정계수는 ITM-01, 02, 04 에만 적용
```

감점을 보정계수로 나누는데, 보정계수는 1 이상이므로 나눌수록 감점이 줄어듭니다. 즉 보정은 점수를 깎는 게 아니라 완화하는 방향으로만 작동합니다. 이 나눗셈은 ITM-01·02·04(가속·감속·차로변경)에만 적용되며, 운전자가 통제할 수 없는 조건을 완화해 준다는 취지입니다.

등급은 다음과 같습니다.

| 등급 | 기준 |
|---|---|
| A+ | 95 이상 |
| A | 90~94 |
| B | 80~89 |
| C | 70~79 |
| D | 70 미만 |

D등급이어도 자동 불이익은 없고, 관리자 확인과 코칭 대상 지정만 수행한다고 명시돼 있습니다.

## 4. 화물 운송 특성 보정 (6.3)

승용차 기준을 화물차에 그대로 쓰지 않으려는 장치입니다. 가점은 없고 감점 완화만 합니다.

| ID | 조건 | 계수 기여 | 근거 |
|---|---|---|---|
| ADJ-01 | 총중량 25톤 이상 | +0.15 | 적재 중량에 따른 제동거리·가속 특성 차이 |
| ADJ-02 | 야간 운행 비율 50% 이상 | +0.10 | 시야 제약 하 방어운전 중 급감속 빈도 상승 |
| ADJ-03 | 악천후 구간 운행 | +0.20 | 강수·적설·안개 조건의 조작은 안전 대응인 경우가 많음 |
| ADJ-04 | 고위험 구간 비율 30% 이상 | +0.10 | 항만·산업단지·사고다발 구간의 구조적 정체와 진출입 특성 |

보정계수는 `1 + Σ(해당 조건 기여값)`이고 상한은 1.55입니다.

## 5. 시뮬레이터로 본 실제 계산 (6.4)

6.4의 시뮬레이터는 위 산식을 그대로 코드로 구현해, 심사나 현장 설명 때 산식이 블랙박스가 아님을 보여 주는 용도입니다.

기본값(412km, 급가속 12·급감속 14·과속 11분·차로변경 6·연속 4.6h·야간 72%·미준수 20%, 총중량 25톤·악천후 체크)으로 직접 계산하면 다음과 같습니다.

- 보정계수는 1 + 0.15 + 0.10 + 0.20 = 1.45입니다.
- 항목별 감점은 가속 약 0.8, 감속 약 1.3, 과속 17.6, 차로변경 약 0.5, 피로 9.8, 환경 3.0입니다.
- 총 감점은 약 32.9점이라 총점은 약 67.1점(D등급)이 됩니다.

여기서 드러나는 특징은, 과속(17.6)과 피로(9.8)가 감점의 대부분을 차지한다는 점입니다. 두 항목은 배점이 각 25점으로 가장 크고 보정도 안 되기 때문에, 사실상 이 모델의 점수를 좌우하는 축입니다. 반대로 가·감속·차로변경은 보정으로 눌려 영향이 작습니다.

## 6. 분석에서 짚어 둘 점

- 이 모델은 조작 실수보다 구조적 위험(과속·피로)에 훨씬 무겁게 반응하도록 배점이 설계돼 있습니다. 100점 중 과속 25 + 피로 25 = 절반이고 둘 다 보정이 없습니다.
- 시뮬레이터에는 문서 표에 없는 Scope 3 감축 추정 로직도 붙어 있습니다. 감축률은 `(총점 − 70) × 0.15%/점` 구조입니다. 기준선이 70점이라 70점 이하는 감축이 0이고, 100점을 받아도 실질 감축률은 약 4.5%입니다. 코드상 상한 8%는 정상 점수 범위에서는 도달하지 않습니다. 5절 기본 예시가 67점이라 감축 추정이 0으로 나오는 것도 이 기준선 때문입니다.
- 임계값과 보정 계수 모두 PoC 잠정값으로 명시돼 있어, 실데이터가 쌓이면 재조정될 값입니다.

## 7. 기사 뷰 프로토타입과의 관계

실무적으로 가장 중요한 부분입니다. 현재 기사 뷰 프로토타입의 점수식은 이 PRD 모델과 완전히 다른 모델입니다.

- 프로토타입은 네 이벤트를 뭉뚱그려 `이벤트율 × 70`으로 한 번에 깎고, 10배 해서 0~1,000점으로 보여 주는 단순 대체식입니다.
- PRD는 6개 항목별 가중 감점 + 보정계수 + 등급으로 된 0~100점 모델입니다.

따라서 기사 뷰가 실제로 어떤 점수를 보여 줄지 결정해야 합니다. PRD 모델을 반영하려면 다음을 다시 설계해야 합니다.

- 표시 범위(0~100 대 0~1,000).
- 항목별 감점 내역 표시.
- 등급(A+~D) 표시.
- 보정계수 노출 방식.

이는 `08-driver-view-screens.md`의 7절 "점수 표시 규칙"과 내점수 탭(5.13) 화면 요소에 직접 영향을 줍니다.
